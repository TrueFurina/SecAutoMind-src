# Security Hardening Baseline（安全加固基线）

> 通用系统/服务加固清单：以"高暴露 × 低修复成本"为优先级排序原则，每项均给出验证方法。面向已授权环境使用。

## 账号与认证

| 项 | 加固动作 | 验证方法 |
|---|---|---|
| 默认口令 | 清点所有服务默认口令（admin/123456/root 等），强制首轮修改 | 弱口令扫描复测 |
| 口令策略 | 最小长度 12 + 复杂度 + 失败锁定（5 次/15 分钟） | 尝试连续错误登录验证锁定 |
| 多因素 | 管理后台与远程接入启用 MFA | 登录流程检查 |
| 最小权限 | 应用禁止以 root/SYSTEM 运行；RBAC 按岗授权 | `whoami` 服务运行身份核查 |
| SSH | 禁用 root 直接登录与密码认证，仅密钥 | `sshd -T` 输出核查 |

## 网络与暴露面

| 项 | 加固动作 | 验证方法 |
|---|---|---|
| 监听地址 | 默认绑定 127.0.0.1；需要对外时经反代+访问控制 | `ss -antup` / `netstat` 核查监听面 |
| 端口收敛 | 关闭非必要端口（管理面/调试口如 2375、8448、6379 对外） | 外部端口扫描复核 |
| 分区隔离 | 管理网段与业务网段分离；数据库不直接暴露公网 | 网络可达性测试 |
| 传输加密 | 强制 HTTPS（TLS1.2+）；禁用 SSLv3/TLS1.0 | `nmap --script ssl-enum-ciphers` |
| 安全组 | 按白名单放行；拒绝默认全通 | 控制台配置审计 |

## 系统与服务

| 项 | 加固动作 | 验证方法 |
|---|---|---|
| 补丁 | 高危漏洞（emergency 级）7 天内修复，其余按月度窗口 | 补丁清单比对 |
| 时间同步 | NTP 校准（日志时间线一致性前提） | `w32tm /query` / `chronyc tracking` |
| 防病毒/EDR | 开启实时防护与外联告警 | 进程与策略核查 |
| 共享与 SMB | 关闭高危共享；SMBv1 禁用 | `net share` / 注册表核查 |

## Web 中间件

| 项 | 加固动作 | 验证方法 |
|---|---|---|
| 目录列表 | 关闭 autoindex/目录浏览 | 访问目录路径复核 |
| 报错信息 | 自定义错误页，禁止堆栈回显 | 触发 404/500 检查 |
| 解析限制 | 上传目录禁执行；Nginx `location` 限制 PHP/ISP 解析 | 上传+访问验证 |
| 管理后台 | 禁外网直连或加 IP 白名单+独立认证 | 远程访问测试 |
| Actuator/调试端点 | 禁用或仅内网+认证 | 访问 /actuator 复核 |

## 日志与审计

| 项 | 加固动作 | 验证方法 |
|---|---|---|
| 日志留存 | 关键日志保留 ≥ 180 天，集中采集 | 存储周期抽查 |
| 登录审计 | 开启失败登录告警与异地登录提醒 | 模拟触发验证 |
| 完整性 | 日志防篡改（只读转发/哈希链） | 修改测试 |

## 数据库

| 项 | 加固动作 | 验证方法 |
|---|---|---|
| 账号 | 禁用默认账号或强口令；应用账号与运维账号分离 | 登录测试 |
| 授权 | 应用账号仅授予所需库表的最小权限（禁 DDL/file 权限） | 权限核查 `SHOW GRANTS` |
| 备份 | 定期备份 + 异机存放 + 恢复演练 | 恢复演练记录 |
| 慢日志/审计 | 开启审计插件，记录高危语句 | 审计日志抽样 |
