# PPT 制作提示词（SecAutoMind 参赛答辩）

> 用途：把 `make_template_ppt.py`（已接入 `演示模板版.pptx` 视觉）与 AI 工具打通。
> 当前状态：脚本已可一键生成 `SecAutoMind_参赛答辩_模板版.pptx`（18 页，视觉来自模板首页全屏背景图，文案/数字由脚本精确控制）。
> 本文给出**三套可直接复制的提示词**：① 视觉模板生成 ② 逐页文案生成 ③ 配图生成。末尾附脚本维护说明。

---

## 〇、先看清「脚本 ↔ 模板」的分工（避免重复劳动）

| 层 | 由谁负责 | 改哪里 |
|---|---|---|
| 视觉母版（背景图、配色、装饰元素） | `演示模板版.pptx` 首页全屏背景图 | 在 PowerPoint 里改模板，或重做模板后让脚本重新引用 |
| 文案与全部数字（18 页内容） | `make_template_ppt.py` 里的 Python 代码 | 改脚本里字符串常量，重跑即更新 |
| 一键出片 | `make_template_ppt.py` → `SecAutoMind_参赛答辩_模板版.pptx` | `python make_template_ppt.py` |

**铁律（评审会挑刺）**：任何量化数字必须先核对，未实测的标注「待验证」，绝不在 PPT 里写没跑过的提升百分比。权威口径见文末「真实数据口径」。

## 一、视觉模板生成提示词（给 AI 设计 / 图像工具）

> 目标：产出或迭代 `演示模板版.pptx` 这类风格。可直接粘给支持「PPT 模板 / 视觉设计」的 AI（如即梦、豆包、Canva AI、Gamma、或 WorkBuddy 图像生成）。

```
请你为「2026 挑战杯网络安全赛道」参赛答辩 PPT 设计一套视觉母版，赛博科技风、冷峻专业、不花哨。

【项目调性】
- 产品：SecAutoMind —— 具备自主决策能力的通用网络安全智能体（多 Agent 编排 + 90 个安全工具 + 知识库 + 人机协同 HITL）。
- 关键词：网络安全、攻防、智能体编排、自主决策、审计留证、国产化模型。

【视觉规范】
- 比例 16:9（13.333 × 7.5 inch）。
- 底色：深空蓝黑 (#0A1128 / #0E1830 渐变)。
- 强调色：青绿 #00FF9D（主强调）、科技蓝 #00B3FF（次强调）、琥珀 #FFB454（警示/数据）。
- 字体：标题与正文均用「微软雅黑 / 思源黑体」，数字用等宽感强的无衬线。
- 元素：细发光线、网格点阵、低饱和电路/盾形/节点连线装饰；首页需有一张铺满 13.333×7.5 的全屏背景图（作为脚本克隆的底层视觉）。
- 禁：高饱和渐变、卡通、大量阴影、与「安全/严肃」调性冲突的活泼配色。

【交付要求】
- 输出 1 个 .pptx，至少含：1 张全屏背景母版页（深色、含盾形/节点装饰、可铺满）+ 1 张标题页版式 + 1 张「章节/内容」版式（留白足够放标题+3~5 个要点+一个数据卡）。
- 版式尽量用「占位符 + 母版背景」而不是把文字烧死在图片里，方便脚本后续注入文案。
```

## 二、逐页文案生成提示词（给 LLM 文案工具）

> 目标：让 AI 基于 `STORY.md` 与真实数据，产出 18 页的每页「标题 / 要点 / 数据卡」纯文本，你再回填进 `make_template_ppt.py` 的对应字符串。
> 也可直接把本提示词 + `STORY.md` 喂给 WorkBuddy 等对话式 AI，让它输出可嵌入脚本的结构化文案。

```
你是 SecAutoMind 参赛答辩 PPT 的文案编辑。请基于下面的「真实数据口径」与「18 页结构」，为每一页产出：
- title：一句话页标题（≤14 字）
- points：3~5 条要点（每条 ≤ 22 字，口语化、评委能秒懂）
- stat（可选）：1 个核心数据卡（数字 + 标签，如「18 / 角色化 Agent」）

【18 页结构】
1 封面｜2 目录｜3 赛题理解(G1-G4)｜4 总体方案｜5 系统架构
6 三层编排(Orchestrator/Planner/Executor)｜7 通用性(90工具/18 Agent)
8 人机协同(HITL approval + 审计)｜9 离线自主(无公网依赖)｜
10-12 三大创新点(事实黑版/工具动态解锁/审计留证)
13 实测验证数据｜14 评分标准对照｜15 部署(一键/腾讯轻量云)
16 应用场景(靶场/应急/蓝队)｜17 总结展望｜18 封底

【真实数据口径 —— 严禁编造，未实测标注「待验证」】
- 工具：90 个 YAML 工具配方
- 角色化 Agent：18 个（15 个场景 + 3 个编排器变体）
- 技能包：23 个（技能文档 27 篇）
- 角色定义：13 个
- internal Go 包：31 个
- 测试文件：226 个；go test：26 个包全绿、0 FAIL
- Go 代码：非测试 111,058 行（含测试 139,427 行）
- 默认监听 127.0.0.1；HITL 默认 approval（赛题硬约束）
- 默认模型通道 qwen-max（模型名 qwen3-max），支持 DeepSeek failover
- 8 个 IM 通道：钉钉/飞书/微信iLink/Telegram/Slack/Discord/QQ 已实现主动连接；企业微信仅回调骨架待补
- 量化提升（成功率/耗时）：尚未在受控靶场实测 → 一律写「待验证」，不写任何百分比

【输出格式】严格按页号给出 title/points/stat 的 JSON 数组，不要解释、不要编造数字。
```

## 四、脚本维护说明（给执行者）

**重生成：**
```bash
cd SecAutoMind_PPT
python make_template_ppt.py        # 输出 SecAutoMind_参赛答辩_模板版.pptx
```

**改数字/文案：**
1. 打开 `make_template_ppt.py`，直接改对应页的字符串（每页以 `# P<N> 标题` 注释分段，便于定位）。
2. 重跑脚本。
3. 用下方校验命令确认无旧数字残留：
```python
from pptx import Presentation
prs=Presentation("SecAutoMind_参赛答辩_模板版.pptx")
blob="\n".join(sh.text_frame.text for s in prs.slides for sh in s.shapes if sh.has_text_frame)
for bad in ["16 Agent","24/26","223 测试","17,927","27 个 internal"]:
    assert bad not in blob, bad
print("OK 无过期数字；页数", len(prs.slides))
```

**已接入的视觉：** 脚本打开 `演示模板版.pptx`，取其首页全屏背景图（13.333×7.5）克隆到每个内容页底层；内容载体用空白 Presentation 以避免与模板残留 slide 重名。若要换更中性的背景，把 `演示模板版.pptx` 首页那张全屏图换成内容页风格的底图即可，脚本无需改。

**已知限制（诚实告知队长）：**
- 当前每页背景都来自模板首页那一张全屏图；若想要「不同页不同底图」，需改为按页型循环引用模板第 N 页背景（改动 `bg()` 里 `_TPL_BG` 的取值逻辑）。
- 模板的矢量装饰形状（半闭框、梯形等）未克隆，仅克隆了背景图片；如需完整模板装饰，建议直接在 PowerPoint 里用「重用幻灯片」把内容稿套进模板版式，或升级脚本做形状级克隆。
- 企业微信通道在代码层尚未实现主动连接（仅回调骨架），PPT 第 7/16 页若提及需加「企业微信：对接中」标注。
