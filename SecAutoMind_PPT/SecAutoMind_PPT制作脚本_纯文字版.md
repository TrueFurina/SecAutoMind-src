# SecAutoMind 参赛答辩 PPT · 纯文字版制作脚本

> 来源内容：`草稿内容版.pptx`（24 页，文字内容满分版）
> 用途：交付给 PPT 设计/制作者，逐页照做即可还原「内容满分 + 视觉专业」的答辩稿。
> 画布基准：16:9，13.33″ × 7.5″（约 2540 × 1425 px @150dpi）。页边距统一 0.5″。

---

## 〇、全局设计系统（全篇统一，先做这一页的母版）

### 0.1 配色（深空科技蓝）
| 角色 | HEX | 用法 |
|---|---|---|
| 背景深 | `#060A1E` | 整页底色（左→右线性渐变到 `#0C1535`） |
| 背景底光 | `#10204A` | 底部/右侧径向光晕，模拟科技光 |
| 品牌主蓝 | `#4874CB` | 主标题色块、章节大数字、强调线、图标 |
| 科技青 | `#30C0B4` | 「我们的方案 / 能力 / 成功」正向语义 |
| 警示橙 | `#EE822F` | 「痛点 / 风险 / 危险操作」负向语义 |
| 实证绿 | `#75BD42` | 「已实测 / 全绿 / 通过」证据语义 |
| 文字主 | `#FFFFFF` | 标题、关键数字 |
| 文字次 | `#AEB9D6` | 正文、说明 |
| 卡片底 | `#16234C`（半透明 82%） | 内容卡片填充 |
| 卡片描边 | `rgba(255,255,255,0.14)` | 细描边；正向卡用青、负向卡用橙描边 |

### 0.2 字体（中文优先，给出回退链）
- **主标题 / 大数字**：`演示创黑FLY Heavy` → `思源黑体 Heavy` → `优设标题黑` → `微软雅黑 Bold`
- **卡片小标题**：`思源黑体 Bold`（或 `微软雅黑 Bold`）
- **正文 / 要点**：`微软雅黑`（或 `思源黑体 Regular`），行距 1.25
- **英文 / 代号（XH-202609、Go、YAML、SQL）**：`Arial` / `Consolas`（等宽更有工程感）
- 字号梯度：章节大数字 100–110pt ｜ 页标题 26–28pt ｜ 卡片标题 16–21pt ｜ 正文 12.5–14.5pt ｜ 页脚 9pt

### 0.3 通用组件（每页复用）
- **页眉条**：左上角小字 `2026 CHALLENGE CUP · 揭榜挂帅 · 安恒信息发榜`（仅封面/章节页；内容页可省）。
- **页脚固定**：左下 `SecAutoMind · 2026 Challenge Cup · XH-202609`（9pt，灰）；右下 `NN / 24`（页码，9pt，灰）。
- **卡片**：圆角 8–10pt，半透明深蓝底 + 细描边；左上角放一个小图标（⚠ 橙 / ✓ 青 / ▣ 蓝 / ◷ 绿）。
- **图标库**：统一用线性图标（Stroke 2px），不用拟物；配色跟随卡片语义色。
- **对齐栅格**：内容安全区 `X:0.5–12.83″`，`Y:0.4–6.9″`；多列卡片列间距 ≥0.3″。

### 0.4 章节分隔页统一规范（第 3/6/12/17/20 页共用）
- 巨大章节序号 `01–05`（110pt，主蓝，左对齐 X≈1.0″、Y≈2.2″）
- 序号下方章节名（40pt，白）
- 再下核心金句（16pt，灰）
- 背景可加该章对应的几何母题（如架构页放分层线、实测页放对勾矩阵），但保持极简，不与内容页抢戏。

## 第 1 页：封面

**1. 页面定位与叙事逻辑**
开场定调：一句话让评委记住「我们是谁、做什么、为哪个赛题」。承接下一页目录，建立「揭榜挂帅·安恒发榜」的权威背书。

**2. 文字内容清单**
- 主标题（英雄字）：`SecAutoMind`
- 副标题 / 核心金句：`自主决策 · 多智能体协同 · 全链路攻防推演平台`
- 上沿小字：`2026 CHALLENGE CUP · 揭榜挂帅 · 安恒信息发榜`
- 说明段：`面向赛题 XH-202609「具备自主决策能力的通用网络安全智能体技术研究」` + 换行 + `以 3 层编排 × 91 工具 × 18 Agent，打造可离线运行的 AI 安全作战指挥舱——双击即用 · 跨平台 · 可验证`
- 底部三枚特性标签：`Windows / Linux / macOS` ｜ `首启向导 · 零配置密钥` ｜ `多 LLM 自动轮询 · 全链路审计`

**3. 视觉排版与元素放置**
- 整体布局：中心偏上英雄式（标题垂直居中略偏上，说明在下，特性标签贴底）。
- 元素坐标与样式：
  - 上沿小字：顶部左 `X0.8 Y0.55`（15pt，灰，字距加宽）。
  - 主标题 `SecAutoMind`：居中偏左 `X0.8 Y2.1 W12 H1.5`（64pt，主蓝+白描边，可加轻微外发光）。
  - 副标题：`X0.82 Y3.3`（24pt，白，字距 2px）。
  - 说明段：`X0.82 Y4.15 W11.6 H1.2`（17pt，浅灰，两行，第二行可把「3 层编排 × 91 工具 × 18 Agent」用主蓝高亮）。
  - 底部三标签：贴底 `Y5.6`，三栏等宽（各 W2.6，X 分别为 0.85 / 3.65 / 6.45），9pt 灰，中间用竖分隔线。
- 视觉强化：主标题后方放一层淡淡的网格/电路纹理（透明度 8%），不要抢字。

**4. 配色与字体**
- 背景：深空蓝渐变 `#060A1E→#0C1535`，右下角加 `#10204A` 径向光。
- 强调：主蓝 `#4874CB` 用于标题与「3 层编排 × 91 工具 × 18 Agent」高亮。
- 字体：标题用演示创黑FLY Heavy；说明用微软雅黑。

**5. 动画与演讲备注**
- 出现顺序：上沿小字 → 主标题（缩放淡入）→ 副标题 → 说明段逐行 → 底部三标签。
- 讲稿：开场 15 秒点题——「我们是 SecAutoMind，一个可离线运行的自主决策攻防推演平台，专为解决安恒 XH-202609 赛题而生。」

> 💡 **微调建议**：可在主标题正上方加一行小字中文品牌名 `闽江睿御 · 智体矩阵`（与「SecAutoMind」中英对照，强化记忆点），字号 18pt 灰，与英文主标题形成「中文名+英文名」双层。

- 六项（序号 / 章名 / 副题）：
  1. `赛题理解与总体方案` —— `XH-202609 要一个怎样的智能体 · 我们做什么`
  2. `核心能力与技术架构` —— `五层架构 · 三层编排 · 91 工具 · HITL 审计 · 离线`
  3. `技术创新` —— `自动选型 / YAML 工具化 / 人类可控 / 产品化闭环`
  4. `产品化与跨平台交付` —— `双击即用 · 首启向导 · 三端 CI · 多 LLM 零配置`
  5. `实测验证与评分对照` —— `编译零错误 · 测试全绿 · 向导/权限/CI 实测`
  6. `部署 · 场景 · 演示` —— `云上跑 · 教学与竞赛 · 演示视频`

**3. 视觉排版与元素放置**
- 整体布局：左侧大标题 `目录` 占 ~30%，右侧六项竖向列表占 ~70%；或全宽两列三行卡片网格（推荐，更稳重）。
- 元素坐标（两列三行卡片方案）：标题 `X0.5 Y0.32`；卡片区 `Y1.4–6.6`，每行两卡，卡 `W5.9 H1.4`，列 X 为 0.5 / 6.9，行 Y 为 1.4 / 3.0 / 4.6。
  - 每卡：左侧大序号 `01–06`（26pt，主蓝）+ 右侧章名（17pt，白，加粗）+ 副题（11.5pt，灰）。
  - 卡左上角放一个主蓝小图标（如 ① 用方块、② 用层级、③ 用灯泡…）。

**4. 配色与字体**
- 同全局；序号用主蓝，当前演讲章可高亮（其余灰），但目录页默认全亮。
- 字体：章名思源黑体 Bold，副题微软雅黑 11.5pt。

**5. 动画与演讲备注**
- 出现顺序：标题 → 六项依次淡入（从左到右、从上到下）。
- 讲稿：快速过一遍六章，强调「第 5 章会用真实工程数据对照评分标准」。

## 第 4 页：赛题 XH-202609 要一个怎样的智能体？

**1. 页面定位与叙事逻辑**
「痛点 vs 评分标准」左右对撞：左讲行业为什么难，右讲赛题怎么打分——自然引出我们下一页的方案恰好对准右侧 5 维。

**2. 文字内容清单**
- 主标题：`赛题 XH-202609：要一个怎样的智能体？`（27pt）
- 副题：`命题单位：安恒信息（揭榜挂帅）——面向真实网络攻防场景，要求智能体「能自主决策、能通用对抗、能人机协同、能证明有效」`（14pt，灰）
- 模块1（左·痛点）：`现实痛点：安全智能体为何难落地`
  - `▸ 告警洪峰与攻击路径复杂：单一 AI 无法完成"分析-决策-执行"闭环`
  - `▸ 工具割裂：Nmap 在命令行、Burp 在 GUI、脚本各写各的，Agent 无法统一编排`
  - `▸ 风险难控：自主执行危险操作缺少审批与审计，不敢真正交给 AI`
- 模块2（右·评分）：`赛题评分结构（5 维度 · 每维 20 分）`
  - `① 自主任务理解能力    自然语言 / 结构化 / 压缩包 / 接口文档 → 可执行计划`
  - `② 多场景自主决策与执行    渗透 / 应急 / 漏洞挖掘 / 逆向，全闭环动态调整`
  - `③ 运行鲁棒性与决策可靠性    可解释 · 可审计 · 可复现，对抗干扰稳定`
  - `④⑤ 人机协同 · 应用成效    HITL 审批 + 现场实战协同 + 部署落地证据`

**3. 视觉排版与元素放置**
- 整体布局：左右分栏，左 46% / 右 46%，中间 8% 留一道竖向分隔光带（暗示「问题→标准」）。
- 元素坐标：
  - 主标题 `X0.5 Y0.32 W12`；副题 `X0.52 Y1.05 W12`（14pt）。
  - 左模块卡：`X0.82 Y1.82 W5.5 H4.25`，橙描边 + ⚠ 图标，标题 `Y1.82`，要点 `Y2.22` 起（13.5pt）。
  - 右模块卡：`X7.02 Y1.82 W5.5 H4.25`，蓝描边 + ✓ 图标，标题 `Y1.82`，四维逐行 `Y2.22`（13.5pt，维度序号 ①②③④⑤ 用主蓝加粗）。
  - 中间分隔：一条竖向半透明蓝光 `X6.7 Y1.9 W0.04 H4.1`。
- 视觉强化：左卡右上角放「告警/碎片」图标，右卡放「评分仪表」图标；两卡底部可各加一句小注（左：行业现状 / 右：赛题硬指标）。

**4. 配色与字体**
