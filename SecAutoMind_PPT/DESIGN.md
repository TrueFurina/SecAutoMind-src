# SecAutoMind 参赛答辩 PPT · DESIGN

## 1. 设计意图

- **受众**：挑战杯“揭榜挂帅”赛题 XH-202609（安恒信息命题）评审专家，关注自主决策、通用性、工具协同、创新性与应用成效。
- **核心目标**：让评委在 15 页内相信 SecAutoMind 是完整、可运行、可落地的网络安全多智能体系统，并对照评分标准逐项呼应。
- **视觉调性**：深色科技风 / 网络安全感 / 数据可信 / 青蓝高亮。
- **视觉策略**：
  - 封面与结束页使用 3D 渲染主视觉 + 暗角蒙版，强化竞赛气场。
  - 章节过渡页使用 SVG 抽象几何底纹（网格、节点、光晕）。
  - 架构/流程/数据页使用 SVG 矢量图，保证缩放清晰。

## 4. 母版与网格

- **画布**：1280 × 720 px，16:9。
- **安全区 padding**：40px（上下左右）。
- **三区母版**：
  - A 标题块：0–120px（含上 padding 40），主标题 32–36px bold。
  - B 内容区：120–640px（可用 520px），正文、图表、配图、卡片。
  - C 页脚条：640–720px（含下 padding 40），左项目名 + 右页码 `NN / 15`。
- **色彩节奏**：Hero 页强调色可提升至 15%；内容页强调色 ≤ 5%。
