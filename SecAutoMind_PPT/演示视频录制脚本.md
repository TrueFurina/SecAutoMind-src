# SecAutoMind 演示视频录制脚本（分镜 · 台词 · 操作）

> 用途：2026「揭榜挂帅」擂台赛 XH-202609 参赛演示视频
> 目标时长：6–7 分钟（评审注意力黄金窗口）
> 版本基线：SecAutoMind v1.7.25（含首启向导 / 跨平台 / 多 LLM / RBAC）
> 录制软件：OBS Studio 或 Windows 自带录屏（Win+G）；1080p / 60fps 最佳
> 演示环境：Windows 11 本机 + 一台已授权的本地靶机（或 DVWA 类 Web 靶场）

---

## 录制前检查单（必须先跑一遍再录）

- [ ] 准备一个**全新空目录**（如 `D:\demo`），复制 v1.7.25 绿色版 exe 进去 —— 用于开场"首启向导"真实演示
- [ ] 靶机可用：`ping` 通 / 浏览器能打开靶场首页
- [ ] LLM 可用：确认 `DASHSCOPE_API_KEY` 环境变量存在（或 config 已配 qwen-max），先手动对话一次确认能回复
- [ ] 屏幕分辨率 1920×1080，窗口缩放 100%（避免字体发虚）
- [ ] 关闭无关弹窗 / 消息通知（重点：微信、钉钉弹窗会毁镜头）
- [ ] 浏览器准备：Edge/Chrome 干净窗口，提前打开两个标签页（http://127.0.0.1:8080 + 靶场首页）
- [ ] 录屏前先完整彩排 2 遍，实测每步点击位置
