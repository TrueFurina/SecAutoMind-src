# SecAutoMind 演示视频录制脚本 v2（与平台一一对应 · 导航指引到位置）

> 用途：2026「揭榜挂帅」擂台赛 XH-202609 参赛演示视频
> 目标时长：6–7 分钟（评审注意力黄金窗口）
> 版本基线：SecAutoMind **v1.7.26 本地版（fix4）** —— 含首启向导 / 品牌图标 / 知识库启用修复 / 多 LLM / RBAC

## 一、录制前环境清单（每一项都要先跑通，再开录）

### 1. 准备演示实例（二选一）
- **方案 A（推荐，用于录制"首启向导"镜头）**：新建空目录 `D:\demo`，把项目根 `secautomind-ai.exe`（fix4）复制进去，**再复制一份 `config.yaml` 并确认 `port: 18086`**（没有 config.yaml 会默认 8080，可能被占）。此目录第一次启动即走全新向导。
- **方案 B（用现有实例）**：直接双击桌面「SecAutoMind」快捷方式（项目根，已是 fix4）。若已完成过向导则看不到向导页——**要录向导就用方案 A**。

## 五、录制常见坑与预案（先看再录）
| 坑 | 现象 | 预案 |
|----|------|------|
| 端口打不开 | 双击后浏览器连不上 | 确认地址是 18086；若被占，停掉占用进程或改 config.yaml 端口后重启 |
| 没出现向导页 | 打开直接是登录框 | data 已存在（非全新）→ 删掉 data 重启 或 用 D:\demo 全新目录 |
| 密码找不到 | 找不到密码文件 | 看 `data\admin_initial_password.txt`（data 子目录）；若文件已删说明向导已完成过 |
| 审计里没有记录 | 列表空白 | 先做镜 4/5 的操作（产生记录）再筛；筛选操作者选 admin |
| 403 弹不出 | auditor 能写 | 角色勾选错误——确认 auditor 成员绑的角色是 auditor（只读），重新添加成员 |
| LLM 不回复 | 对话无响应 | 查 AI 通道是否激活 + 密钥是否有效；先手动发一句测试 |
| 靶机不可达 | 工具执行失败 | 换已授权靶机或 DVWA；录前 ping 通验证 |
