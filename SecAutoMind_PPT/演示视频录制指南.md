# SecAutoMind 演示视频录制详细指南（环境 · 操作 · 避坑）

> 配套文档：`演示视频录制脚本.md`（分镜与台词）
> 本文档解决"怎么把脚本顺利录出来"，含环境准备、OBS 配置、录制纪律、常见坑与应急预案。

---

## 一、环境准备（提前一天完成，录前再验一遍）

### 1.1 演示机规格
| 项 | 建议 |
|----|------|
| 系统 | Windows 10/11（64 位），虚拟机或实体机均可 |
| 内存 | ≥ 8 GB（平台 + 浏览器 + OBS 同开） |
| 网络 | 能访问 dashscope（千问 API）+ 本机靶场 |
| 显示器 | 1920×1080，**缩放 100%**（100% 是关键：缩放 125% 会让界面模糊、按钮错位） |

### 1.2 目录与账号准备
1. 建干净演示目录 `D:\demo`，仅放一个文件：`secautomind-ai.exe`（v1.7.25 绿色版）
2. 把**演示用专属密码**提前定好（如 `Admin@Sec2026`）并写在手边便签
3. auditor 只读演示账号：需要先用 admin 在「设置 → RBAC」创建 auditor 用户，密码写便签
4. 靶机/靶场：DVWA 或 Metasploitable 等**已授权**靶机，确认能 ping 通、浏览器可访问
5. 环境变量：`DASHSCOPE_API_KEY` 必须已设置（建议加到**系统环境变量**，避免只有当前终端可见）

### 1.3 预演（最重要的一步）
- 按脚本完整走 **2 遍以上**，用秒表计时
- 记录每处卡顿点（如"审批卡片弹出位置""对话回复耗时"），在台词里预留等待时间
- 预演时把每一步的实际点击路径记下来（对话示例文本放剪贴板备用）

## 二、OBS Studio 录制配置（推荐）

### 2.1 基础设置
| 项 | 值 |
|----|-----|
| 输出 → 视频 | 1920×1080，60fps（或 30fps 也可），比特率 15–20 Mbps |
| 输出 → 录音 | 麦克风（人声）+ 桌面音频（可选，建议关闭避免杂音） |
| 画布 | 显示器采集（全屏）或 窗口采集（只录浏览器 + 平台，画面更干净） |
| 热键 | 开始/停止录制：建议 F9/F10，避免录进去 |

### 2.2 录制纪律
1. **先录环境声 5 秒**再开口（后期对白校准用）
2. 每镜之间停顿 1 秒，方便剪辑
3. 说话时鼠标移动要慢而稳（快速甩鼠标在成片里很晃眼）
4. 不要边录边看屏幕角落的录制指示——提前把 OBS 预览窗口移到副屏（若单屏，用小窗口模式）

## 三、分镜实操注意点（对应脚本）

| 镜头 | 实操注意 |
|------|---------|
| 镜 1 开场卡 | 提前用 PPT 第 1 页截图做 3 秒定场，别真去录 PPT 翻页 |
| 镜 2 首启向导 | **成功率关键**：全新空目录首次双击 → 向导必现。若曾运行过（有 data 目录）向导不会出现 → 用新目录或删掉 data 再来 |
| 镜 3 界面巡礼 | 提前把各页面打开一遍，确认无报错红条（红条是事故镜头） |
| 镜 4 信息收集 | 对话文本提前复制在剪贴板；等 Agent 输出完成再切旁白；工具执行慢时旁白补充解说 |
| 镜 5 HITL 审批 | 审批卡片有倒计时，批准要果断；想展示"拒绝"路径就单独录一个小片段 |
| 镜 6 审计 + RBAC | auditor 账号切换要顺畅（密码便签放屏幕旁）；403 红字出现后停 2 秒再说话 |
| 镜 7 跨平台 | 提前录 Linux 虚拟机启动片段；现场只演示 Windows 即可 |
| 镜 8 收尾 | 数据淡入用剪辑做，别现场敲字 |

## 四、高频坑与应急预案

| 坑 | 现象 | 预案 |
|----|------|------|
| **向导不出现** | 双击直接进登录页 | data 目录残留 → 删除 data 重新启动（演示前检查） |
| **端口被占** | 双击后浏览器打不开，服务没起 | 先 `tasklist | findstr secautomind` 杀掉旧实例再启动 |
| **登录 401** | 密码错误 | 密码文件 `data\admin_initial_password.txt` 里的值才是初始密码；登录后请用演示密码 |
| **对话无响应/超时** | Agent 卡住 | 检查 DASHSCOPE_API_KEY；平台会自动轮询其他通道，等 10–20s；预演时确认该任务能完成 |
| **靶机不可达** | 扫描无结果 | 预演确认 ping 通；备用：演示"平台对不可达目标的优雅降级"（展示审计里的失败记录） |
| **OBS 忘开麦克风** | 成片无声 | 录制前测试音；设置里开"监听"确认 |
| **录到一半失误** | 说错/点错 | 别停！说一句"这段重来"，继续操作——剪辑时剪掉即可；镜头内失误比冷场好救 |
| **SmartScreen 拦截** | 双击弹"已保护你的电脑" | 预演时点"更多信息 → 仍要运行"过一遍；正式录前若再弹，属正常演示点（可解说"未签名软件的正常提示"） |

## 五、发布规格（提交用）
| 项 | 建议 |
|----|------|
| 格式 | MP4（H.264 + AAC）|
| 分辨率 | 1920×1080 或 1280×720（平台要求若低，720p 足够）|
| 时长 | 5:30–6:30 |
| 片头 | 3 秒深色品牌卡（项目名 + 赛题号 XH-202609 + 安恒信息）|
| 片尾 | 官网 https://truefurina.github.io/SecAutoMind/（2 秒）|
| 字幕 | 建议加中文字幕（剪映/Toolwhisper 自动生成后校对）——评委可能静音看 |
