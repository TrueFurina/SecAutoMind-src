## T-30 分钟 · 先证明「交得上去」（不做就必然 0 分）

```bash
python scripts/race_submit_probe.py --platform ctf2 \
    --competition <比赛uuid> --stage <阶段uuid> --challenge <任一题uuid>
```

| 输出 | 含义 | 动作 |
|---|---|---|
| `✅ 通道通` | 端点存在、鉴权通过 | 继续 |
| `❌ 令牌坏`（40403/401） | 令牌无效/过期/无权限 | **停下来换令牌**，别开赛 |
| `❌ 路径错`（404） | 平台/赛事/题号不对 | 核对 uuid，别猜 |
| `🚨 异常`（2xx） | 探针不该提交成功 | 立即人工核查 |

探针体固定 `{}`，**不可能真的提交**，可以放心跑。

## T-10 分钟 · 上膛

```bash
source scripts/finals_arm.sh
```

看确认表四行：

- `目标平台` —— `CTF² 竞技场（auto）` 还是 `DASCTF（dasctf）`
- `<平台>_BASE_URL` —— 必须是对应平台（`pro.dasctf.com` ≠ `ycb-bk.dasctf.com`）
- `CTF2_AGENT_TOKEN` / `CTF_AGENT_PLATFORM_TOKEN` —— 前缀对不对（`ctf2_` / `ak_`）
- `CTF_SCOREBOARD_SNAPSHOT=true` + `INTERVAL=300` —— 分数心跳已开

只想看表、不跑门禁：`bash scripts/finals_arm.sh --table`（1 秒）。

## T+0 · 分诊（10 分钟内必须出表）

```bash
python scripts/race_triage.py --from-json <平台导出的题目.json> \
    --check-targets --out board.md
```

**从上往下打，跳过两类**：

- `大概率已交`（已解出 >10 队）—— 打了也是重复
- `⚠️ 靶机死·需重建` —— 先要环境，别硬打

`--check-targets` 会 TCP 探活每个直连靶机：题目 JSON 里的 `status: running`
**会过期**（10-24 的 12061 标着 running、实际早死了）。

> 没有导出 JSON 就先导出。**分诊表不联网、不需要令牌**——
> 别把「没令牌」变成「分诊也做不出来」。

## 每次开新尝试前 · 止损检查

```bash
python scripts/race_stoploss.py check --challenge <题号> || echo "→ 换题"
```

失败发生的那一刻记，不要事后补：

```bash
python scripts/race_stoploss.py record --challenge <题号> \
    --class <guess|tool_missing|env_dead|wrong_path|timeout|format>
```

规则：**同题同类失败 2 次** 或 **单题累计 5 次** → 退出码 1，必须换题。
（10-24 我在一道题上做了 863 次无法验证的比对，没人拦。）

## T+15 / T+30 / … · 看分数

排行榜心跳已在上膛时打开（每 300 秒一次）。

**15 分钟分数没动 → 停下来问「是不是方向错了」，不是继续磨。**
这是复盘里最贵的一条：不可测量的指标不会被优化。

### 赛后：账本在 `logs/scoreboard.jsonl`

心跳不只打日志，还会**逐条落盘**（`internal/ctfplatform/scoreboard_ledger.go`）：

```bash
# 看分数走势（每行一条：ts / kind / overview）
tail -20 logs/scoreboard.jsonl
```

`kind` 为 `periodic`（周期）或 `final`（停轮终报）。路径可用 `CTF_SCOREBOARD_LOG` 覆盖。
**复盘时先看这个文件**——2026-10-24 那场就是因为没有它，事后只能靠回忆。

## 硬规则（贴在屏幕上）

1. 进展**只按已交 flag 数**计。文档、工具、测试、门禁一律记 **0**。
2. 解题**不需要令牌**，只有提交需要。
3. 同题同类失败 **2 次 → 换题，不解释**。
4. 开赛前 5 分钟必做：扫 `.workbuddy/tmp/` 看并行会话已产出什么 → 抽直连地址 → 确认提交通道。
