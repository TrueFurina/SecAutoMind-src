## 三、本轮最重要的两处修复

### ① `TestHTTPClientReuse` 是**恒假断言**（SA4000）

```go
if p.HTTPClient != p.HTTPClient {          // 左右同式，永远 false
    t.Fatal("HTTPClient 应复用同一实例（连接池）")
}
```

这个用例挂在"⑦ HTTP 连接复用"名下，从写下那天起**从不验证任何东西**——
却让所有读者以为这条契约有回归保护。

改成验证 `anti_block_config.go` 里那条真会出事的规则：**关闭连接复用时必须
克隆私有 Transport，不得改动进程级 `http.DefaultTransport`**（源码注释里明确
警告过：直接改 DefaultTransport 会让"回退动作自身变成事故源"）。新断言四步：
默认 Transport 为 nil → 关闭复用后 DefaultTransport 未被污染 → 私有 Transport
的 `DisableKeepAlives=true` → 重新开启时 client 实例不变（连接池不被丢弃）。

### ② `invokeEinoGraph` 的 `for {}` 恒执行一次（SA4004）

三条分支全部 `return`，循环体不可能跑第二遍。去掉 `for` 是**行为等价**改写，
注释里写明：续跑由调用方带 `resume=true` 重新进入本函数完成，不是靠这个循环；
将来要原地续跑多轮，入口应显式写在这里——**不因为 SA4004 就自作主张加语义**。

## 四、豁免台账（不修，每条带理由与复核日期）

完整机器可读版本见 `scripts/staticcheck_baseline.json`。要点：

| 项 | 为什么不修 |
|---|---|
| SA1012 ×10 | 测试**故意**传 nil Context（`TestWithPrincipalNilCtxAndEmptyUser` 即写"nil context is safe"）。改成 `context.TODO()` 会**失去这条覆盖**——静态检查建议与测试意图冲突时以测试意图为准 |
| ST1005 ×2 | 中文错误文案以专有名词 `Agent` 开头触发"首字母不得大写"；中文语境不适用，改小写破坏对外文案 |

| U1000 ×110 | 死代码台账，只登记不删；清理需逐个确认是否有外部/反射引用，另立任务 |
| SA4006 ×3 | `bestLike`（出块后只读 best）、`taskIndex`（二次查找必然覆盖，防 TOCTOU）——死存储属实但删掉会丢语义，已就地加注释 |
| SA5011 ×1 | 假阳性：同一函数上方已 `range result.Content` 解引用，nil 时更早已 panic |

## 五、门禁：只拦新增语义缺陷

**不设"零告警"**——首日就红的门禁，唯一结局是被 `--no-verify` 绕过。分两档：

| 档位 | code | 行为 |
|---|---|---|
| 阻断 | SA4000 / SA4004 / SA4006 / SA5011 / SA9009 / ST1008 | 计数超基线即 exit 1 |
| 观察 | S1xxx / SA1012 / SA1019 / ST1005 / U1000 | 只提示；`--strict` 下也红 |

另外两条硬规则：

1. **基线键 = (code, 仓库相对路径)，不含行号**。本轮实测：删掉两行循环后
   U1000 行号整体漂移，行号做键会凭空多出 2 条"新增"（REA #258 同款）。
2. **基线未登记的语义类 code（SA4/SA5/SA9 前缀）直接红**——不许靠"没登记"
   蒙混过关，必须先裁定归属阻断档还是观察档。

fail-closed：报告缺失 / 为空 / 全部行无法解析 → exit 2（扫不到 ≠ 干净）。

自测 14 项（`scripts/check_staticcheck_baseline_test.py`），含"已知坏样本必须红"
（新增 SA4006 必须红、未登记的 SA5001 必须红）、MSYS 路径改写后仍能归一化、
豁免条目必须有 reason + reviewed_on。
