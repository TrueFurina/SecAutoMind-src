## 二、S6 录制前置（最重要的一步，漏了就是白录）

**HITL 默认审批方是 AI（audit_agent），人工卡片不会弹！** 新建会话后必须先设置：

- Web 界面：会话设置 → HITL → 开启 / approval / **审批人选 human** / 超时 600s
- 或 API（注意是**扁平**字段，必须带 `enabled:true`）：
  ```bash
  curl -X PUT http://127.0.0.1:18086/api/hitl/config \
    -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
    -d '{"conversationId":"<cid>","enabled":true,"mode":"approval","reviewer":"human","timeoutSeconds":600}'
  ```
- **自验**：`GET /api/hitl/config/<cid>` 应显示 `enabled:true, mode:approval, reviewer:human`。

**S6 剧本实测（kimi，共两轮 ≈35 万 tokens）**：
1. 第一轮发任务 → nmap 调用被人工队列拦下 → **点拒绝** → Agent 明确回复"尊重裁决，不绕过审查"
2. 第二轮发"我确认这次扫描是必要的，请再次执行" → nmap 再次进队列 → **点放行** → 连同后续 exec 一起放行 → 真实扫描结果（8501 等端口）
3. 任务词："请使用 nmap 工具对 127.0.0.1 的 8500-8510 端口做一次端口扫描，告诉我开放了哪些端口"
