# 现场演示 Checklist（容灾手册 · 2026-09-05）

> 目标：任何单点故障下 60 秒内恢复演示。赛前通读，赛时按序执行。
> 平台实测端口：`config.yaml` → `server.port`（当前 18086）；沙盒验证用 18099。

## 一、出发前 24 小时（在家完成）

- [ ] `go build`/CI 最新 tag 三端产物下载可用；携带**两个 U 盘**各存一份：Setup exe（33MB）+ 绿色版目录（152MB）
- [ ] 产物 MD5 校验记录在案（防止 U 盘拷贝损坏）
- [ ] 演示机：提前装好绿色版 + 创建桌面快捷方式；**关闭杀软实时扫描误报白名单**（Go 单文件常被误报）
- [ ] 备用浏览器（Edge/Chrome 便携版）+ 离线演示录屏视频（完整跑一遍的高清录屏，最终兜底）
- [ ] 手机热点可用 + 主办方网络信息（WiFi/代理）已询问确认

## 二、到场后 30 分钟（部署窗口）

- [ ] 双击 exe → 观察控制台 `● ONLINE http://127.0.0.1:18086` → 浏览器自动打开
- [ ] 首启向导：设强密码（**别用演示机键盘记忆**：输完点"显示密码"核对一遍）
- [ ] 冒烟五连（全部通过才放手）：
  - [ ] `GET /` → 200
  - [ ] 对话页发一句话任务 → 有响应（验证 LLM 通道活着）
  - [ ] 工具页可见工具列表（page_size=100）
  - [ ] 审计页有记录
  - [ ] HITL 配置页可打开
- [ ] 端口冲突预案：若 18086 被占 → `config.yaml` 改 `server.port: 18099` 重启（改码不必，改配置即可）

## 三、演示中故障 → 对策表

| 故障 | 症状 | 60 秒对策 |
|------|------|-----------|
| LLM 通道故障 | 对话无响应/报 4xx | 对话设置切 `aiChannelId`（qwen↔deepseek↔zhipu 任一可用通道，实测切换 2 秒生效）；若全挂 → 切**离线录屏**讲架构 |
| 端口被占 | 启动报 listen failed | 改 port 重启（见上） |
| 杀软拦杀 | exe 消失/拒运行 | 恢复隔离区 + 加白；不行换 U 盘第二份 |
| 浏览器缓存异常 | 页面白屏/旧资源 | Ctrl+Shift+R 强刷；换备用浏览器 |
| 数据库锁 | 报 SQLite busy | 关掉多余实例（**只跑一个 exe**）；重启实例 |
| WiFi 断网 | 全部外部调用失败 | 热点；同时强调"数据全本地，断网不丢审计"——把故障变成离线卖点的演示机会 |
| 触发 HITL 卡住 | 任务停在审批 | 这不是故障！当场演示"审批拒绝"路径（评审爱看），或点放行继续 |

## 四、演示叙事锚点（对照实测证据）

## 五、红线

- ❌ 现场不跑任何未实测过的操作路径
- ❌ 不当评委面输错密码三次以上（防锁定逻辑不确定行为——先在部署窗口验证）
- ❌ 不承诺"永不故障"，只演示"故障后可控"（切通道/降级/离线兜底）
