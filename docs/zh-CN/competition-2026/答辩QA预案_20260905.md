## Q1. 你们的量化指标很多写着"未开展/小样本"，怎么证明有效性？

**诚实边界**：作品报告第四章的六项指标里，环境识别、专家盲评、24 小时长稳、低配内存当时确未开展，我们不回避。
**已做工作**：9/5 已完成系统性实测补强——自建三场景可复现靶场 + 六组实验（多场景识别/端到端成功率/可复现性/抗干扰/多策略对照/跨工具链），真实任务决策链 63 事件留痕、140 个运行时工具实测、HITL 拒绝路径实证，全部原始数据可复现（`docs/evidence-20260905/`）。
**演进路线**：终审前用主办方 120 小时仿真平台，把每项指标补到统计意义上的样本量，并以官方环境数据为准。

## Q2. 第一环节要经 AI 安全网关接入，你们准备好了吗？

**诚实边界**：目前是 OpenAI 兼容预留（base_url 可指向网关），未拿到主办方网关地址前无法端到端联调。
**已做工作**：多 LLM 通道架构原生支持第三方网关（8 通道运行时实测）；通道健康探测与失败降级内建（qwen 欠费→deepseek 接管已实测）；报备所需的通道/模型/密钥信息已环境变量化不落盘。
**演进路线**：网关地址下发后 24 小时内完成接入验证（配置改动即可，无需改代码）；同步提交报备清单。

## Q3. "3 名队员 + AI Agent 协同"，Agent 和队员怎么分工？

**诚实边界**：当前平台是"单人对多 Agent"形态，多人多席位并发作战模型在建设中。
**已做工作**：平台已有多用户 RBAC（实测 auditor 只读隔离 403）、批量任务队列（多任务并行、状态可视、cron 重跑）、全链路审计（谁做了什么可追溯）——协同的三块地基已实测。
**演进路线**：席位模型 + 任务池原子领取按决赛就绪度清单推进（见 final-race-readiness 文档），并在仿真平台做 3 人协同实练。

## Q4. 和安恒"恒脑"是什么关系？会不会就是套壳？

**诚实边界**：我们与恒脑无代码关系，也未接入恒脑 API；平台调用的是通用大模型 API（qwen/deepseek 等，备案合规）。
**已做工作**：SecAutoMind 的价值在模型之上的工程层——18 角色 Agent 编排、90 个 YAML 工具配方、事实黑板、HITL 审批、审计回放，共 120,813 行 Go，全部原创可审查。模型可替换：网关、本地模型、任意 OpenAI 兼容端点都能接。
**演进路线**：恒脑若开放 API，平台可作为其工具执行层互补接入。

**已做工作**：多通道自动探测+切换（实测）；数据全本地（SQLite+文件知识库）；前端内嵌二进制离线可用；危险操作有 HITL 兜底不会失控执行。

## Q8. 你们说"可复现"，怎么证明？

**诚实边界**：可复现≠每次输出逐字相同（LLM 本质如此），指决策路径与结论可重现。
**已做工作**：决策链 63 事件全量入档可回放；自建靶场脚本化一键重建（ground truth 自动判分）；实验原始数据 JSON 随材料提交；`scripts/experiments/` 提供一键重跑。

## Q9. 为什么用 Go 而不是 Python？（可能被追问技术选型）

**诚实边界**：Python 生态在安全工具侧更丰富，Go 在交付形态上有硬优势，我们两者并用（Go 主体 + Python 工具脚本沙箱）。
**已做工作**：单文件跨平台二进制（Win/Linux/macOS 原生编译，含 cgo sqlite）、152MB 绿色版双击即用、无 Python 环境依赖——这是"部署便捷高效"（评分维度② 17-20 档）的直接支撑；安全工具侧保留 execute-python-script 沙箱调用 Python 生态。
**演进路线**：持续扩大 YAML 工具配方库，Go 壳 + Python 芯双轨并行。

## Q11. 你们的 8 通道容错，什么情况下会失效？（E-19）

**诚实边界**：failover 只对瞬时故障（429/5xx/网络抖动）自动切换；对通道级永久失效（如某通道欠费 400）按设计不接管，任务直接失败。
**已做工作**：这是有意设计——避免把请求发往已知坏通道浪费配额与延迟；判定逻辑单点收敛在 `isEinoTransientRunError`，全系统共用一套规则（代码注释明确"其它模块不维护平行规则"）。实测 + 代码级根因链见 E-19。
**演进路线**：赛后区分"请求级 4xx"（参数错误，不应浪费其他通道）与"通道级 4xx"（欠费/无效 key，故障在通道不在请求 → 应自动切下一通道）；现场规避手段是保证默认通道可用（充值或切换 default_channel）。
**加分点**：能当场说出 `isRetryableHTTPStatus` 只认 408/409/425/429/5xx——评委问容错最怕背宣传语，这个答案有代码级精度。
