## 二、必主动声明的三件事（别等被问）

1. **执行层与 Web 层是自建靶场 / 自造题**：执行 15 道真工件（PNG/JPEG/ZIP/PCAP 魔数实测为真）+ 2 道活靶机；Web 7 道真利用链 + 3 道源码 / Cookie 泄漏。**不代表真实赛场能力，仅验证求解器逻辑正确性。**
2. **静态缺口是输入信息量上限，不是能力上限**：55 题中 **35 题描述中根本无数据**（如「浏览器 Cookie 中 Base64 编码的 flag」），静态不可解；能解的 20 题本仓全解 → 静态口径已饱和。补数据实测不可行（公开参数 sha256 不匹配、占位题无对应原题）。
3. **LLM 是严格子集，护城河没被追平**：裸 LLM 并集 19/55，本仓确定性求解器 20/55，**LLM 解出的题本仓全解出、仅 LLM 解出的 0 道** → 本仓在可解题上 100% 覆盖。模型差异是「犯不同的错」，主模型失败后换模型重试比死磕一个更值（但 failover 仅在 API 报错时切，答案错不切，要利用得改代码）。
