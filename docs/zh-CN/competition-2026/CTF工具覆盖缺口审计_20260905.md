# 90 工具 CTF 实战覆盖缺口审计（T3 · 2026-09-05）

> 目的：终审实战赛（60%）按题型统计得分，本题库盘点 90 个 YAML 工具对 CTF 各类题型的覆盖情况，给出补齐建议。
> 口径：`tools/*.yaml` 磁盘实数 90；运行时可调用 140（90 YAML + 50 内置，evidence E-11）。

## 一、覆盖良好（CTF 高频题型有对应工具）

| 题型 | 已有工具 |
|---|---|
| 逆向 | **angr**（符号执行）、**ghidra**（反编译）、gdb、checksec、john、hashcat |
| MISC-文件 | **binwalk**、foremost、exiftool、unzip 类（execute-python-script 兜底） |
| WEB | sqlmap、ffuf/feroxbuster/gobuster/dirsearch、dalfox（XSS）、arjun（参数）、graphql-scanner |
| 信息收集 | nmap、fscan、amass、dnsenum、fofa_search、gau |
| 密码 | hashcat、john、hydra、hashpump |
| 万能兜底 | **execute-python-script**（沙盒 Python：zipfile/base64/PIL/rsa 全可写）+ exec |

**结论**：MISC/CRYPTO/REVERSE/WEB 四大类都有起步工具，且 execute-python-script 可实现几乎全部 CTF 解题脚本（西湖论剑经验：解题主力就是"Python 沙盒 + 方法论"，不依赖外部二进制）。

## 二、缺口（建议 11 月前补齐，按性价比排序）

| # | 缺口 | 影响 | 补法 |
|---|---|---|---|
| 1 | **ctf 常见编码族**（brainfuck/摩斯/与佛论禅/rot 族/各种 base 变体一键识别） | MISC 送分题丢分 | 新增 1 个 YAML 配方调 python 脚本：`ctf-decode-multibase`（自动识别+解码链） |

## 三、Skill 层建议（用户已拍板暂缓实施，仅备案）

西湖论剑验证过的高价值解题知识（移植清单，待 11 月前用官方仿真平台打磨时实施）：
