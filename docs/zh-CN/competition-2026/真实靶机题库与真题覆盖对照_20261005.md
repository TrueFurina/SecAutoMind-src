# 真实靶机题库与真题覆盖对照（2026-10-05）

> 目的：把"真实靶机"从一次性探针扩成**可复用的题库**，并给出它对真实真题的覆盖度，
> 让"自产题占比 60.7%"这件事有改进路径与可量化口径。
>
> 诚实边界（先说清，避免被读大）：
> 本题库的靶机是**按真实漏洞形态手写的最小实现**，不是原题复现——原题靶机不可得
> （picoCTF 已迁移、API 403，见 `真机联调记录_20261005.md`）。
> 因此它验证的是**链路与题型覆盖**，**不等价于"能解出原题"，也不产生任何新得分率数字**。

## 四、口径来源（可复核）

```bash
python -c "
import json,collections
d=json.load(open('data/ctf_benchmark/real_coverage_report.json',encoding='utf-8'))
miss=[r for r in d['results'] if not r.get('sha256_match')]
print(collections.Counter(r['sub'] for r in miss).most_common())
"
```

⚠️ 判据字段是 `sha256_match`（flag 哈希），**不是** `hit` —— `results` 里没有 `hit` 字段，
误用会让 72 条全部"未命中"（本轮已踩过一次，见项目记忆）。
