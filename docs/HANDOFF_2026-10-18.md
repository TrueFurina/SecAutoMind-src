  - nmap 长许可证截断为「Nmap Public Sou…」，title 留全文「已核实许可证：Nmap Public Source License」
  - 深色主题下三色均在场、可读
  - 唯一 console 报错是 harness 的 `file://` fetch 警告（无害，非 JS 错误）

1. **JS 测试无 CI 驱动**：仓库现有 17+ 个 `*.test.cjs`，但 `ci.yml` 全文无 `node --test`、无 Makefile 驱动——全是孤儿测试。新测试沿用同一惯例，只能手工 `node --test` 跑。要接 CI 需先确认 CI 环境有 Node。
2. **全量测试未跑服务器**：按实验服务器规则，涉及全库的测试应在 `172.16.222.99`（Go 1.25.4）执行；本机只跑了 config/handler/app 三包。全量 `go test ./...` 在 C/D 盘空间紧张时曾有 GOCACHE 并发抖动（knowledge/multiagent 偶挂），建议 `go list ./... | grep -v ctfplatform` 分流跑或先清 GOCACHE。
3. **审计脚本未接 CI**：它是盘点工具，不是门禁；升级为门禁前需补回归测试与变异验证。
4. **`radare2` 混合许可**只记 `LGPL-3.0`；**`terrascan` 上游已归档**（`tenable/terrascan`）。字段是单值，装不下 SBOM。
