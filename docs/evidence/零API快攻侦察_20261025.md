## 一、对账结果（机检，非目测）

- `real_coverage_report.json`：55 题中 **39 题 sha256_match=False**；
- 逐题 description 审计：

    `flag{REDACTED_...}` 占位——**脱敏抹掉了可解材料**，题在生成时就不可解；

    为**教学方法句**（如"RSA共模攻击：n1和n2共享素数p"），无密文/无编码串/
    无附件引用——**材料在靶机**（picoGym/BUUCTF 在线环境），本地零材料；
- 判定：这 39 题是"靶机依赖题"，确定性 solver 与 LLM 同样无米下锅。
  **在 benchmark.json 层面没有可零 API 快攻的目标。**

## 二、立尺附注（口径）

- static 36.4% 覆盖率的"未覆盖 39"，其中 ≥35 是**结构性不可离线解**——
  该覆盖率的天花板被题集设计钉死在 ~64%，不是求解器能力问题。
  建议观澜/出题侧知悉：若要让 static 集合具备"离线可解性审计"价值，
