## 5. 为什么仍不是能力证据

1. **零私有题**：154/154 公开，模型记忆与公开 writeup 无法排除。
2. **判分不去壳未修**：本批次已知假阴性 0，但 `verify_flag()` /
   `candidate_variants()` 仍在他人 WIP 与共享文件里未改；将来模型若答对
   裸内容真值题仍会判不中。两条守卫守住的是池，不是判分口径。
3. **题面结构性不可解**：v1 全量实测题面中位数 78 字符、最短 1 字符，
   23 题需附件而本路径未传 `--artifact-dir`。
4. **agentic 路径未跑**：`CTF_AIRGAP=1` + IP 直连证明 + 单通道 +
   判据接进 `solve_one()` 都还没做。
