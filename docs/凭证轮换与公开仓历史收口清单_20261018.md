## 3. 最终验收：全量反查脚本（可在本地跑）

```bash
# 对 PUBLIC 仓完整对象流（含全部分支/tag/refs）做指纹流式反查
git clone --mirror https://github.com/TrueFurina/SecAutoMind.git /tmp/sm_mirror
cd /tmp/sm_mirror
for fp in "<旧千问key前16位>" "<旧飞书secret前16位>" "<旧QQtoken前16位>"; do
  n=$(git rev-list --objects --all | awk '{print $1}' \
      | while read o; do git cat-file -p $o 2>/dev/null | grep -c "$fp" || true; done \
      | awk '{s+=$1} END{print s+0}')
  echo "$fp -> $n"
done
# 三行全部为 0 = 收口完成；任一非 0 = 回到 §2
```

> 注：`git cat-file` 逐对象较慢，可换 `git grep "$fp" $(git rev-list --all)` 或对 `git rev-list --objects --all` 输出走 `git cat-file --batch` 提速。仓库大时优先用 GitHub API 的 secret scanning 报告交叉验证。

## 4. 防复发（机制已具备，补两条纪律）
