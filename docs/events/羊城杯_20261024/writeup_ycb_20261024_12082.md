## 五、六问六答

### Q1 隧道域名（注册域）
`e-cdn81.net`
（沙箱查询的是 `*.update-check.metrics.e-cdn81.net`，取后两段标签）

### Q2 被盗令牌（核心技巧）
报告里给了 5 个「配置指纹」：

```
#1 ~/.gitconfig        → KBAVILJZ
#2 ~/.git-credentials  → IY2EWMSN
#3 credential.helper   → FVITGR2J
#4 url.insteadOf       → KQ3S2Q2P
#5 http.sslVerify      → KJIDIUY
```

拼起来是 **39 个字符**，正是 24 字节的 base32 长度（8 字符=5 字节，7 字符=4 字节 → 5×4+4=24）：

```python
import base64
s = "KBAVILJZIY2EWMSNFVITGR2JKQ3S2Q2PKJIDIUY"
base64.b32decode(s + "=")      # b'PAT-9F4K2M-Q3GIT7-CORP4S'
```

→ `PAT-9F4K2M-Q3GIT7-CORP4S`

**关键**：agent 实际只查了 4 个（跳过 #1），4 段只能解出 19 字节 `F4K2M-Q3GIT7-CORP4S`，
不完整。必须把 #1 也算进去才是完整令牌——这是本题最容易做错的一步。

## 六、这次踩的两个坑（比题目本身更值得记）

### 坑 1：提交时带了 `flag{}` 外壳 —— 白烧 25 次提交

README 写「flag 格式：`flag{问题1_..._问题6}`」，我照字面拼了 `flag{...}` 提交，
连续 25 次全部返回 `40001 提交flag错误`。**实际平台只比对花括号内的裸内容**：

```
flag{e-cdn81.net_...}   → 40001 提交flag错误
e-cdn81.net_...（裸）    → isCorrect: true
```

**代价**：六个答案在第 3 分钟就全对了，剩下 30 分钟全花在怀疑第 4 问的取值上
（14:22 / 10:31 / 10:33 / UTC / 12 位 / 13 位 / 带秒 / ISO 全试了一遍）。

**判据**：当 N 次尝试全部失败、而某一维你在**每次尝试里都没变过**，那个维度就是 bug。
第一次失败后就该做通道对照：拿一个已知正确的串，裸/带壳各发一次，30 秒定位。

### 坑 2：把「已解出的题」当噪声
日志里有 42 个员工在查 `e-cdn81.net`（随机 hex 标签），只有 EMP_107 的 4 个标签是 base32。
如果只按「域名出现次数」排序，会直接漏掉真隧道——必须**先定受害者，再定隧道**。

## 七、可复用脚本

```python
import json, base64, re

S  = "EMP_107-2026-0915-b41d77e0"    # 注入会话
SB = "EMP_107-2026-0915-c93f2a14"    # 沙箱会话

frags, q1, q4, q5, q6 = [], None, None, None, None
for line in open("orchestration_logs.json", encoding="utf-8"):
    e = json.loads(line)
    if e.get("session_id") == SB and e.get("tool") == "dns_query" and q1 is None:
        d = e["args"]["query"].rstrip(".").split(".")
        q1 = ".".join(d[-2:])
    if e.get("session_id") == S and e.get("direction") == "s2c" and not frags:
        frags = re.findall(r"→ ([A-Z2-7]+)", e["result"]["content"][0]["text"])
    if e.get("session_id") == S and e.get("tool") == "write_file" \
       and "gitconfig" in str(e["args"].get("path")):
        m = re.search(r'url "https://([^/"]+)', e["args"]["content"])
        q6 = ".".join(m.group(1).split(".")[-2:])
    if e.get("session_id") == S and e.get("tool") == "read_file" \
       and "/docs/" in str(e["args"].get("path")):
        q5 = e["args"]["path"].split("/")[-1]

q2 = base64.b32decode("".join(frags) + "=").decode()
print(q1, q2, "107", q5, q6)
```

> 注意：`q4` 取的是**首次 mcp_transaction c2s**（`2026-09-15T10:31:05` → `20260915T1031`），
> 不是写 `mcp_servers.json` 的时间（那只是登记），也不是写 gitconfig 的时间（那是篡改）。
