- 与 S1 `hash_md5`、S2 `hash_md5_ctf` **完全同类**：模型即使调 execute，沙箱也**没有 rockyou/词表**，MD5 还原 = 爆破题 → 必 MISS。
- 这 14 道不是模型能力问题；S4/S5 命中率会显著低于 S1/S2，**勿误读成"能力缺口"**。
- **要让这 14 道可解，二选一（否则按"环境不可解"单列）：**
  1. 给沙箱装词表：`apt install wordlists` 或把 `rockyou.txt` 放到 `/usr/share/wordlists/`，并在 prompt 里允许 `hashcat -m 0` / `john --wordlist=rockyou.txt`；
  2. 或 prompt 注入"常见弱口令词表（letmein/dragon/master/monkey/shadow/superman/batman/football/welcome/abc123/qwerty/654321/password1/iloveyou…）"让模型字典攻击——多数 hash_* 题面明文就是这些弱口令，可解。
- **建议**：S3 直接跑；S4/S5 先按上述方案解决词表，再跑，否则如实单列"环境不可解"。
