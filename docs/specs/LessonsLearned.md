# LessonsLearned — 门禁/CI 每红一次，登记一条

> 机制（2026-10-24 设立，对应业界 Red Hat spec-coding 的 LessonsLearned.md 反馈环）：
> 任何门禁/CI/测试**非预期变红**且归因成立后，在本表登记一行；**登记动作写进 `AGENTS.md` 方法论红线节的配套规则**。
> 目的：把每次红灯从"故障"变成"下次不犯的资产"——与 P-10 避坑经验回写同构，但触发点固定为门禁红灯。
