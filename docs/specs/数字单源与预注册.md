# 数字单源与预注册（硬规矩，2026-11-04 立）

> 起因：项目反复出现「自己出数字 → 自己出报告把数字证伪 → 把证伪当进展汇报」的自证循环。
> 实证：83 份日志只有 3 个数字可以说话；外池 40 题中 16 题（40%）真值可从公开仓库直接下载；
> `protocol_fail` 与 `empty_reply` 双桶重复计数；2026-10-27 一批交付只写在工作树、未入库，8 天后归零并留下 5 条悬空登记。
> 本文件只做一件事：**让数字要么有外部锚点，要么不存在。**

## 1. 数字必须有 artifact（五要素）

任何进文档、进汇报、对外的数字，必须同时给出：

| 要素 | 要求 |
|---|---|
| 产出脚本 | 可复跑的脚本路径 + 命令 |
| 输出路径 | 日志 / json / 截图 的真实文件路径（工作树以外落盘亦可，但须可追溯） |
| 时间与版本 | 产出时间 + `git rev-parse --short HEAD` |
| 分母定义 | 分母是什么、排除了什么、样本量多少 |
| 产出者与审计者 | 产出会话/agent id；**审计方必须是另一方** |

缺任一项 → 文档里只能写「未测 / 不可归因」，**不许写数字**。

## 2. 预注册（先提交口径，再测量）

测量开始前，先把四件事写进该 evidence 文档首段并提交：

1. 分母（例：11 题面 = 13 个目录 − 2 个无 json）
2. 排除项（dryrun 夹具 / 需外部环境 / 0 秒污染 / 跳过题）
3. 成功判据（flag 命中一律用 `flag_util.flag_sha256_hit`，禁用原文比对）
4. 样本量与随机种子 / 模型与并发参数

测后改口径 = 该数字作废，必须标注版本并重新测。

## 3. 审计不自证

造数的会话**不得**作为自己数字的审计方。审计必须满足其一：

- 独立脚本（第三人可复跑，输出可 diff）
- 另一会话 / 另一台机器复核

自审结果只能定性为「线索」，不得写成「终裁」；`复盘` 类文档不得以「终裁」命名，除非附第二方复核记录。

## 4. 证伪不是进展

「发现自己的旧数字不可信」只能进 `LessonsLearned.md` 或证据文档的勘误段，**不计入进展汇报**。

进展只计两类：
- **能力增量**：解出率 / 覆盖率 / 单题耗时（必须满足 §1 五要素 + §2 预注册）
- **交付物增量**：可运行、可复现、有验证输出的产物

「提交数 / 文档数 / 门禁 job 数增加」一律不算进展。

## 5. 违规判定（评审直接打回）

- 文档出现无 artifact 的数字 → 未完成。
- 同一会话既产数又出终裁 → 结论降级为线索。
- 用测量活动替代能力建设并对外汇报 → 注水。
- 交付只写工作树、不入库 → 视为未交付（本仓 10-27 实证）。

## 检查清单（贴进 PR / 交接卡 / evidence 文档头）

```
[ ] 每条数字有 (脚本, 输出路径, 时间+HEAD, 分母, 产出者)
[ ] 口径已预注册（在本文件首段，先提交后测）
[ ] 审计方 ≠ 造数方（脚本可复跑或第二方复核）
[ ] 证伪内容未计入进展
[ ] 交付已入库（commit 或外部快照），不是只写工作树
```
