# SecAutoMind 项目一页纸（三创赛 v0.1 草案）

> 状态：**v0.1 草案**（2026-10-25 起草）。依据仓库内既有权威口径与两场比赛实证写成；
> 三创赛官方模板/递交要求/当前赛程待用户补充后对齐格式。数字口径见文末「证据出处」。

## 一句话定位

**SecAutoMind 是一套"多智能体协同的网络攻防竞赛系统"**——用确定性求解器阵列 + 多模型
推理集群 + 容器化靶场 + 全流程证据门禁，把 AI 战队打 CTF 比赛这件事从"玩具 Demo"
变成"有战绩、可审计、能复现"的工程系统。

## 问题（为什么做）

- CTF（网络安全夺旗赛）是检验 AI Agent 实战能力的最佳考场：题型跨 Crypto/Pwn/Web/
  Misc/Reverse，限时高压，答案唯一且机器判分——**没有"讲故事"空间，只有行或不行**。
- 但现有 AI 打 CTF 的方案普遍是"单模型 + 一把梭"：没有技能沉淀、没有失败退避、
  没有证据文化，成绩不可复现，更无法回答"它为什么解出来了/为什么没解出来"。

## 方案（我们做了什么）

四层架构，对应四个真问题：

| 层 | 回答的问题 | 关键设计 |
|---|---|---|
| 确定性求解器阵列（189 个：194 求解器 + 59 检测器） | "常见题型零成本秒解" | 不靠模型"想"，靠算法直接算；26 个基准集全部接线，每个集带**反注水断言**（防自证式假命中） |
| 多模型推理集群（solver swarm） | "难题靠多路探索" | 4 模型并行攻同一题，兄弟 insight 互相注入，失败退避 + 单题硬超时止损 |
| 容器化靶场 | "工具调用安全执行" | Docker 沙箱 + 环境槽位管理 + 退出交还（比赛中真实踩过 409 槽位泄漏，已工程化修复） |
| 证据门禁文化（25 项 CI 门禁） | "成绩凭什么可信" | 密钥扫描/诚实口径/反注水/二进制版本对齐……**结论必须有证据，没有输出的"已修复"一律不算** |

## 证据（不是规划，是已发生）

- **2026-10-24 CTF² 快闪赛（AI Agent 赛道）：9/9 全解，平台得分 1049，冻结排名 47/参赛队**
  ——平台 API 实拉核验，非自算（标分合计 974 + 75 奖励分，口径已留痕）。
- **两场比赛的失败被转化为纪律**：羊城杯 25 次提交错格式的教训 → 固化出"提交通道先于
  解题""提交失败先疑格式不疑答案"的赛时铁律 + 每平台提交格式注册表；快闪赛 runner 两次
  被内存打死的教训 → 起飞前内存韧性守卫（<1G 拒启/<2G 压模型）。
- **静态基准饱和**：CTF 静态基准 55 题中可解的 20 道全部解出（20/20），并如实记录
  "35 道无数据静态不可解"——**不把不可解包装成可解**。
- **赛后回放验证（10-25 首批，进行中）**：把羊城杯赛时未解题回放进引擎持续爬坡——
  12082（赛时人工仅拼出 4/6、害我们提交 25 次的那道题）**agent 独立解出全部六问**，
  含人工卡住的 PAT 令牌重组；受阻 2 题归因诚实（图片题需视觉模型、ML 题沙箱缺 torch），
  均属环境账非接线账。赛时基线 1/26 → 回放验证循环已打通（网关缓存命中后单题成本近零）。

## 差异化（为什么是我们）

1. **证据文化即产品**：别家 Demo 展示"AI 解出了一道题"，我们展示"这道题为什么解出、
   那个数字凭什么可信、那次失败变成了哪条纪律"——25 项门禁 + 反注水断言是别家没有的。
2. **人机协同的真实战绩**：1049 分是平台判的，不是自己说的；连"本地模型跑不动完整栈"
   这种边界都被实测封档（4 模型逐个试错，数据在案）。
3. **工程化止血速度**：比赛事故（互踩容器/槽位泄漏/内存猝死/格式错）当晚变成门禁与
   守卫代码——这是系统演进能力的直接证明。
