## 4. 关键机制（跑之前必须知道）

- **并发策略**：静态题并行（max-concurrent 内）；**容器题严格串行**——CTF² 平台限制每个 Agent 同时仅 1 个靶机环境（`agent_environment_limit`），runner 已按此排序+自动释放（解完 DELETE environment）。
- **自动提交**：solver 解出 flag 立即 `POST /submit/`（`{"flag","confirmation":true}`），平台返回 accepted 即停；重复 flag 自动去重；错误提交冷却 escalate（0/30/120/300/600s）。
- **进入动作**：`POST /api/open/v1/user/agent/competitions/{id}/join/`（正式赛未开放时返回 400 COMPETITION_FULL，开赛后重试；final_entry 会自动重试至 entered=true）。
- **题目更新**：runner 每 5s 轮询，已解不再重复跑；新题出现自动拉取。
