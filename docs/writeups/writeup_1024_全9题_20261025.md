## 二、逐题 writeup

### 1. 签到·二进制问候（Misc, 24）【赛后复现】

**题面**：`greeting.txt`，一整段用空格分隔的 8 位二进制串。

**解法**：按空格切开，每组 `int(b, 2)` 转字符即可。

```python
t = open("greeting.txt", encoding="utf-8").read()
"".join(chr(int(b, 2)) for b in t.split())
```

**结果**：`DASCTF{b1n4ry_w0rld_1024_s4ys_h1} welcome to the binary side! 1024 bits, 128 bytes, eight per group: flip them back to text and ...`

**坑**：flag 后面还跟着一段欢迎语，**不能整段当答案提交**——要按 `}` 截断。

### 2. 19:24 卡点题（Misc, 50）【赛后复现】

**题面**：`moments.txt`，一份值班群聊天导出（23 条）。规则是「19:24 我让 bot 说彩蛋暗号」。

**解法**：全文只有 3 个 `DASCTF{...}`，逐个排除：

| 出现位置 | 串 | 判定依据 |
|---|---|---|
| 19:05:33 | `DASCTF{st4le_fr0m_l4st_we3k}` | 正文明确写「已经作废了，谁再交我笑话谁一年」 |
| 19:16:12 | `DASCTF{n0p_th1s_1s_a_j0ke}` | 正文写「整活…（不是」，下一句「别捣乱，会被当真的」 |
| **19:24:07** | `DASCTF{6b063406-1183-4fac-b54f-f1380907a179}` | **值班 bot 发的【卡点提醒】，且时间戳正好落在 19:24:00–19:24:59** |

**坑（这题的设计核心）**：前两个诱饵**出现得更早**。任何「正则扫全文取第一个 flag」
的策略都会先命中 `st4le_fr0m_l4st_we3k` 然后判错。
必须把**语义线索**（作废 / 整活 / 官方 bot + 时间窗）作为筛选条件，而不是出现顺序。

> 这条直接对应事故模式库 **#10「先到先得假命中遮蔽」**：
> 多候选必须验真者优先，不是先到先得。

### 3. 1024 秒闪电战（Misc, 100）【赛后复现】

**题面**：`run.py`（6 指令栈机：`PUSH/POP/DUP/SWAP/XOR/EMIT`）+ `tape.txt`（1024 行）。
默认能量 512，跑一半就退出并提示「--energy 与纸带等长才是满能量」。

**解法**：题目自己把答案告诉你了——`--energy 1024`。

```bash
python run.py tape.txt --energy 1024
# → DASCTF{27d8fd29-935b-46d7-a9c6-57f6032a61e0}
```

**坑**：默认参数是**故意设成跑不完的**。凡是「工具默认值导致输出不完整」的题，

### 4. 1024 个漏洞故事（Misc, 100）【赛后复现】

**题面**：`stories.json`（1024 条记录，字段 `id/year/sector/vector/sev/story`）+ `BRIEF.md`。
暗号被拆成 **6 片**，藏在方括号记号里，绝大多数是诱饵。从 `VULN-1024` 出发，
沿「与 XX 行业 YYYY 年的另一起事件同出一手」这条句式走 6 跳。

**解法**：爬链，每跳取方括号内容，按链条顺序拼接。

```python
import json, re

items = json.load(open("stories.json", encoding="utf-8"))
cur = next(x for x in items if x["id"] == "VULN-1024")
pieces = []
for _ in range(6):
    pieces.append(re.search(r"\[([^\]]+)\]", cur["story"]).group(1))
    nxt = re.search(r"与(.+?)行业(\d{4})年的另一起事件同出一手", cur["story"])
    if not nxt:
        break
    sec, yr = nxt.group(1), int(nxt.group(2))
    cand = [x for x in items if x["sector"] == sec and x["year"] == yr]
    assert len(cand) == 1, f"下一跳不唯一：{sec}/{yr} 命中 {len(cand)} 条"
    cur = cand[0]

print("DASCTF{%s}" % "".join(pieces))
```

**实跑链条**（可复现验证）：

| 跳 | 记录 | 行业/年 | 取到的片 |
|---|---|---|---|
| 1 | VULN-1024 | 游戏 2021 | `e7ae65` |
| 2 | VULN-0491 | 医疗 2021 | `99-40b` |
| 3 | VULN-0888 | 政务 2023 | `1-4508` |
| 4 | VULN-0865 | 制造 2021 | `-9fd5-` |
| 5 | VULN-0599 | 能源 2023 | `0ed816` |
| 6 | VULN-0539 | 物流 2015 | `906df6`（正文「溯源断了线」，链条终止） |

拼接：`e7ae6599-40b1-4508-9fd5-0ed816906df6` → `DASCTF{...}`（正好是一个 UUID 的形状）。

**可复用点**：
- 链式题的**每一步都要断言唯一性**（`assert len(cand)==1`）。命中 0 条说明句式没对上，
  命中多条说明条件不够——两者都应该立刻停下来查，而不是「随便挑一条继续」。
- 1024 条记录里做全量扫描是 O(n) 的，别上手就写模糊匹配；先看清 `BRIEF.md`
  把「唯一命中」这件事写死了，这就是题目给的保证。

### 6. 1024 端口（Misc, 102）【赛中实证】

**题面**：靶机跑一个 HTTP「许愿池」，规则藏在首页：

```
POST /wish
body 必须正好 1024 字节，以 WISH: 开头、以 :1024 结尾
```

**解法**：

```python
body = b"WISH:" + b"A" * (1024 - 5 - 5) + b":1024"
# len(body) == 1024
urllib.request.Request(url + "/wish", data=body, method="POST",
                       headers={"Content-Type": "text/plain"})
```

**结果**：`DASCTF{a0c43e30-cce0-44de-9723-6e4ae42baf0c}`

**坑（这题真正卡住 solver 的地方）**：靶机地址一开始是 `Target not found` ——
不是解法问题，是**环境槽被一道已解题目的泄漏环境占着**（平台每 Agent 只给 1 个环境）。
释放后 1 分钟解出。这条对应事故模式库 **#18「跨会话协调缺位」**，
现在由 `ctf-agent\scripts\env_guardian.py` 自动兜底。

**可复用点**：「请求长度必须精确 N 字节」这类题，**先算再发**，
不要用字符串乘法凑（`"A"*(1024-10)` 很容易差 1），写完立刻 `print(len(body))` 断言。

### 7. 第 1024 行（Web, 148）【赛中实证】

**题面**：单文件 Flask 应用 OpsDesk（~1100 行），评审组留话「问题就在第 1024 行」，
flag 在靶机 `/flag`。

**解法**（四步）：

1. **静态定位**：直读 `app.py` 第 1024 行附近——`resume_state_object()` 的 legacy 分支
   对用户可控 `state` 做 **`pickle.load`**（`POST /api/v1/session/resume`）。
   前置条件是 `CONFIG["legacy_compat_mode"]` 为 True，否则不可达。
   源码里其它「看起来危险」的段落都是诱饵。
2. **确认开关**：`GET /api/v1/meta` 直接返回 `"legacy_compat_mode": true`（version 2.4.1-demo）。
   **不用猜，应用自己承认脆弱路径是开的。**
3. **构造反射型 payload**：漏洞点的回显链是
   `jsonify({"resumed": True, "state": safe_json_loads(json.dumps(obj, default=str), obj)})`
   —— `default=str` 会对 pickle 还原出的任意对象调 `__str__`。于是：

   ```python
   class P:
       def __reduce__(self):
           return (builtins.eval, ("open('/flag').read().strip()",))
   payload = base64.b64encode(pickle.dumps(P())).decode()
   ```

   `eval` 是内建函数、可按引用 pickle；`__reduce__` 执行后返回 flag 字符串本体，
   经 `default=str` 原样回显——**零外带信道、一发命中**。
4. **发射**：`POST /api/v1/session/resume`，body 走文件避免 shell 吞引号。

**结果**：`DASCTF{461603ee-07a4-44b4-9ad4-f74c937f4a5a}`

**可复用点（三件套）**：`__reduce__ + eval + 回显函数的 default=str`
适用于一切「pickle 落地后对象被序列化/字符串化输出」的题。
另外两个习惯：① 先看应用自曝的配置位（`/meta`、`/debug`）再猜环境；
② payload 首字节不能是 `{`（否则走 JSON 分支绕开 pickle），pickle 流天然满足。

### 8. RSA-1024（Crypto, 150）【赛后复现】

**题面**：`task.py` 注释已经把弱点写明了——「熵源坏了，两个素数几乎是同一时刻出生的」。
`p ≡ q ≡ 3 (mod 4)`，`e = 1024`，`m = bytes_to_long(FLAG.ljust(127, b"."))`。

**解法（两步，都有坑）**：

**第一步：Fermat 分解。** p、q 相近 → `a = ceil(sqrt(n))`，检查 `a² - n` 是否完全平方。

```python
a = isqrt(n); a += a*a < n
while True:
    b2 = a*a - n; b = isqrt(b2)
    if b*b == b2: p, q = a-b, a+b; break
    a += 1
```

本题**第 0 次迭代就命中**（p、q 只差约 2^256 量级），秒出。

**第二步：e 不可逆。** 这里是最容易卡住的地方：

```
gcd(e, phi) = gcd(1024, (p-1)(q-1)) = 4    # 因为 p≡q≡3 mod 4 → p-1、q-1 都是 2×奇数
```

`pow(e, -1, phi)` 直接抛 `ValueError: base is not invertible`。但有个干净的办法：

```
d1 = inverse(e/4, phi/4)        # 256 与 phi/4（奇数）互素，可以求逆
y  = c^d1 mod n
   = m^(1024·d1)
   = m^(4·(256·d1))
   = m^(4·(1 + k·(phi/4)))
   = m^4 · (m^phi)^k
   = m^4                        # 欧拉定理：m^phi ≡ 1
```

于是 `y` 恰好等于 `m⁴`，再做**两次模 n 开方**（p、q 都 ≡ 3 mod 4，用
`v^((p+1)/4)` 开方，每组 2 个解，CRT 合并）→ 4 个候选 → 取 UTF-8 可解且含 `DASCTF` 的那个。

**结果**：`DASCTF{7caf3b46-d3d5-4f78-b004-8feccae97a82}`（后面跟 71 个 `.` 补齐）

**可复用点**：
- 看到 `e` 是 2 的幂（1024 = 2¹⁰）就要想到「**e 和 φ 必然不互素**」，别在
  `pow(e,-1,phi)` 上浪费时间。`gcd(e,phi)=g` 时先求 `e/g` 对 `phi/g` 的逆，
  把问题降成「求 g 次方根」。
- 题目里 `p % 4 == 3` 的断言不是装饰——它就是「开方可用 `v^((p+1)/4)`」的许可条件。

## 四、可复用清单（下次直接抄）

1. **多 flag 场景必须做语义筛选**，不能取第一个（卡点题的三个暗号）。
2. **工具默认参数导致输出不完整**时，先读源码找限制，别猜（闪电战 `--energy`）。
3. **链式题每跳断言唯一性**，命中 0 或多都要停（漏洞故事）。
4. **`e` 是 2 的幂 ⇒ gcd(e,φ)≠1**，走 `e/g` 降阶再开方（RSA）。
5. **pickle + `default=str` 回显 = 零外带信道**（第 1024 行）。
6. **精确长度协议先算再发，写完立刻断言长度**（1024 端口）。
7. **靶机 404/Target not found 先查环境槽**，不是先怀疑解法
   —— 现在由 `ctf-agent\scripts\env_guardian.py` 自动处理。
