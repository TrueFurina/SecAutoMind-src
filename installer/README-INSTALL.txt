SecAutoMind v1.7.18 安装说明
==============================

SecAutoMind —— 自主决策通用网络安全智能体（2026 中国青年科技创新「揭榜挂帅」擂台赛 · 安恒信息发榜 · XH-202609）

一、快速开始
1. 安装完成后自动启动，或双击桌面「SecAutoMind」快捷方式
2. 浏览器将自动打开 http://127.0.0.1:8080
3. 使用首次启动生成的账号密码登录（仅显示一次，请立即保存）

二、SmartScreen 提示
本程序为自编译未签名版本，首次运行 Windows 会提示「已保护你的电脑」。
点击「更多信息」→「仍要运行」即可（属正常现象，非病毒）。

三、卸载
「设置」→「应用」→「SecAutoMind」→ 卸载；或在开始菜单运行「卸载 SecAutoMind」。
卸载会保留 data/ 用户数据目录（本机数据库、日志）。

四、使用边界
本工具仅可对您拥有或已获书面授权的系统、靶场与教学环境执行操作。
AI 通道需自行配置国内备案大模型 API Key（如通义千问），平台不含任何预置密钥。
